# 演示素材目录

这个目录存放 README 中引用的**演示截图与录屏**。仓库默认不附带图片（避免仓库体积膨胀），
所以在你把自己的截图放进来之前，README 里的图片位置会显示为破图 —— 这是**预期行为**。

## 需要的文件

请按下表的**精确文件名**放置，README 与本文档都引用了这些名字：

| 文件名 | 内容要求 | 建议尺寸 |
| --- | --- | --- |
| `home.png` | 主界面：悬浮球开关、快捷入口、当前模型 | 1080 × 2340 左右 |

## 拍摄建议

### 截图

1. **用真机拍摄**，不要用模拟器 —— 模拟器没有状态栏信号、没有真实的悬浮球体验。
2. 系统语言设为**简体中文**，深色/浅色模式请**统一**（建议深色，悬浮窗对比度更好）。
3. **抹掉隐私信息**：通知栏的聊天内容、状态栏的时间可以保留，但请确认画面里
   **没有任何真实 API Key、手机号、真实姓名、聊天记录**。
4. 截图后**不要裁剪**状态栏与导航栏，保留完整的手机画面更有说服力。
5. 建议**不缩放**直接上传（1080px 宽）；如果超过 1MB，压缩到 80% 质量即可。

### GIF 录屏

1. 用系统自带的屏幕录制或 `adb shell screenrecord /sdcard/demo.mp4` 录制。
2. **控制在 5~15 秒**：太长读者不会看完，太短看不出流程。
3. 录制前先清理通知栏与桌面图标，避免暴露个人信息。
4. 转成 GIF（推荐 [ffmpeg](https://ffmpeg.org/)）：

   ```bash
   # 先压到 720px 宽、12fps，再转 GIF（体积可控）
   ffmpeg -i demo.mp4 -vf "fps=12,scale=720:-1:flags=lanczos" -y demo.gif
   ```

   GIF 超过 5MB 会明显拖慢 README 加载，必要时进一步降帧率或缩短时长。

## 提交前检查

- [ ] 6 个文件**文件名完全一致**（区分大小写：`home.png` 不是 `Home.PNG`）。
- [ ] 图片中**不含任何 API Key**（设置页截图的 Key 输入框必须是掩码状态）。
- [ ] 不含手机号、真实姓名、聊天记录、定位等个人隐私。
- [ ] 单个文件不超过 5MB，`demo.gif` 不超过 8MB。
- [ ] 已在本地用 Markdown 预览确认 README 能正常显示这些图片。

## 其他说明

- 这些图片**不参与构建**，放在这里是给 GitHub 页面与文档使用的。
- 如果你不希望把自己的真机截图放进仓库，也可以**只修改 README 中的图片链接**指向外部图床，
  但请确保是长期有效的地址，并在 PR 描述中说明。
- 图片使用**手机原生分辨率**即可，不需要做圆角、阴影或手机外框等后期处理。
